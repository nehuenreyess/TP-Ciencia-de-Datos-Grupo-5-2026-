# Trabajo Práctico Final – Ciencia de Datos | Grupo 5

**FCE – Universidad de Buenos Aires · 2.º cuatrimestre de 2026**

Análisis de las diferencias salariales entre graduados universitarios argentinos según características académicas y sociodemográficas. El proyecto combina estadística descriptiva, inferencia, regresión lineal y medidas de desigualdad.

## Contenido del repositorio

- `tp_grupo05/`: proyecto reproducible en R, con scripts numerados, funciones auxiliares, diccionario y documentación.
- `TP_Final_Grupo5.pptx`: presentación de la entrega final.

## Cómo empezar

Abrí `tp_grupo05/tp_grupo05.Rproj` en RStudio, instalá los paquetes indicados en `tp_grupo05/README.md` y ejecutá `script/00_correr_todo.R` desde la raíz del proyecto.

La base de microdatos no se incluye en Git por su tamaño. El README interno contiene la fuente pública y explica cómo ubicarla en `tp_grupo05/raw/` con el nombre esperado por los scripts.

Para el detalle de las hipótesis, la metodología, las decisiones de limpieza y la reproducción completa, consultá [`tp_grupo05/README.md`](tp_grupo05/README.md).
