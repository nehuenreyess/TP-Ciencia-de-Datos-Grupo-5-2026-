# TP-Ciencia-de-Datos-Grupo-5-2026-
Trabajo Práctico Final de Ciencia de Datos para Economía y Negocios (FCE-UBA). Análisis de las diferencias salariales entre graduados universitarios según sus características académicas y sociodemográficas, utilizando técnicas estadísticas, modelos de regresión y medidas de desigualdad.
